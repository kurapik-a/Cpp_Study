# 职工管理系统

一个基于 C++ 的职工信息管理系统，主要用于学习 C++ 面向对象编程的核心概念（封装、继承、多态）以及手动内存管理。

## 项目结构

```
职工管理系统/
├── include/            # 头文件
│   ├── worker.h        # 职工抽象基类（纯虚函数接口）
│   ├── employee.h      # 普通职工类（继承 worker）
│   ├── boss.h          # 老板类（继承 worker）
│   └── workManager.h   # 管理系统类（菜单、增删改查等功能的声明）
├── src/                # 源文件
│   ├── main.cpp        # 程序入口
│   ├── worker 类实现相关 cpp
│   └── workManager.cpp # 管理系统各功能的具体实现
└── .vscode/            # VS Code 编译调试配置
```

## 功能说明

程序启动后显示主菜单，支持以下功能：

| 编号 | 功能         | 说明                                        |
| ---- | ------------ | ------------------------------------------- |
| 0    | 退出管理程序 | 结束整个系统                                |
| 1    | 增加职工信息 | 批量添加职工，可选择岗位（普通职工 / 老板） |
| 2    | 显示职工信息 | 遍历输出所有职工信息                        |
| 3    | 删除离职职工 | 按编号删除指定职工                          |
| 4    | 修改职工信息 | 按编号修改职工信息                          |
| 5    | 查找职工信息 | 按编号或姓名查找职工                        |
| 6    | 按照编号排序 | 升序 / 降序排列职工                         |
| 7    | 清空所有文档 | 清空全部职工数据                            |

## 核心设计

### 1. 继承体系与多态

`worker` 是抽象基类，把职工的**公共属性**（编号、姓名、部门编号）和**公共接口**（展示信息、获取岗位名称）抽出来：

```
            worker（抽象基类）
           /                \
     employee             boss
    （普通职工）         （老板）
```

```cpp
class worker {
public:
    int id;                // 职工编号
    string name;           // 职工姓名
    int deptid;            // 部门编号
    virtual void showInfo() = 0;    // 展示个人信息（纯虚函数）
    virtual string getDeptid() = 0; // 获取岗位名称（纯虚函数）
    virtual ~worker();              // 虚析构函数
};
```

不同子类对同一接口有不同实现，例如 `getDeptid()`：

- `employee` 返回 `"员工"`
- `boss` 返回 `"老板"`

这样管理系统只需持有 `worker*` 指针，调用 `showInfo()` 时会根据**实际对象类型**自动执行对应版本——这就是多态。

### 2. 动态数组扩容

系统内部用 `worker**` 二级指针管理一个指针数组，容量不足时按"三步走"扩容：

```
1. new 一个更大的新数组
2. 把旧数组里的指针逐个搬运过来（搬运地址，不复制对象）
3. delete[] 释放旧数组，成员指针改指向新数组
```

### 3. 内存管理

- 每个职工对象通过 `new` 创建，存入指针数组；
- `worker` 基类析构函数声明为 `virtual`，保证通过基类指针 `delete` 时能正确调用子类析构；
- 程序结束时由 `~WorkManager()` 统一释放：先逐个 `delete` 职工对象，再 `delete[]` 指针数组本身。

## 二级指针内存模型 `WorkManager`

```cpp
class WorkManager {
    int       m_empnum;   // 有几个职工
    worker **m_emparr;   // 就是上面那个 wk
};
```

```
WorkManager 对象（栈上）
┌─────────────────────────┐
│ m_empnum = 3            │
│ m_emparr = 0x8000 ──────┼──→ [0]0x5000 [1]0x6000 [2]0x7000   （堆：指针数组）
└─────────────────────────┘         ↓          ↓         ↓
                                 employee    boss    employee    （堆：职工对象）
```

释放时**两层各管各的**：

```cpp
for (int i = 0; i < m_empnum; i++)
    delete m_emparr[i];   // 沿第二道门，释放每个职工对象
delete[] m_emparr;        // 释放第一道门后面的那排格子本身
```

### 记忆口诀

> **指针里存的是地址；二级指针存的是"指针的地址"。**
> 每多一级 `*`，就多隔一道门；数组的 `[i]` 就是"跳第 i 道门"。
> `new` 出来的每一层，`delete` 时都要还——先还对象，再还格子。

## 编译与运行

依赖：`g++`（支持 C++11 及以上）

```bash
# 进入 src 目录编译
cd src
g++ -g -I../include ./*.cpp -o build/main

# 运行
./build/main
```

也可以直接在 VS Code 中按 `Ctrl+Shift+B` 使用 `.vscode/tasks.json` 中配置的编译任务。

## 学习要点

本项目覆盖了以下 C++ 知识点：

- 类的封装、继承、多态三大特性
- 纯虚函数与抽象类
- 虚析构函数的必要性
- 一级指针 / 二级指针与堆内存操作
- `new[]` / `delete[]` 的配对使用
- 程序的菜单交互流程控制（`while` + `switch`）
